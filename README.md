# RAG Document Assistant

A local Retrieval-Augmented Generation (RAG) application.

## Features

- PDF loading
- Text chunking
- HuggingFace embeddings
- FAISS vector search
- Streamlit interface

## Architecture

PDF
↓
Chunks
↓
Embeddings
↓
FAISS
↓
Similarity Search
↓
Relevant passages
